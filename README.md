# 山大学习辅助 Windows 应用 · 1.1 MVP

面向需要减少鼠标操作的同学：登录后，在已适配的课程页面按每课要求时长自动切换。使用 Windows 原生窗口和 WebView2，无需安装脚本管理器。

**[下载 Windows x64 应用包](https://github.com/ho2006/sdu-accessible-study/raw/refs/heads/main/dist/SDU-Accessible-Study-win-x64.zip)** · [SHA-256 校验值](dist/SDU-Accessible-Study-win-x64.zip.sha256)

## 直接使用

1. 下载上方压缩包，将整个文件夹解压到本地；不要直接在压缩包中运行 EXE。更新时先退出旧版，再解压到新文件夹。
2. 打开文件夹内的 `SDU-Study.exe`。也可以用键盘选中后按 Enter 启动。
3. 在应用内完成学校登录。应用使用独立的隐私浏览会话，不会复制普通浏览器的登录状态。
4. 当个人中心仅有一个可学习任务时，自动打开任务，按列表顺序选择未达到网站时长要求的课程。多个任务需要先通过键盘或辅助设备选定目标。
5. 自行阅读。每项内容加载稳定后，应用按该课程显示的要求时长计时，到时自动返回列表并选择下一项。窗口处于后台或用户做笔记时计时继续。

应用没有自动朗读、自动滚屏或阅读速度设置。当前页的展示时间只是导航间隔，不代表已经理解课程。

## 暂停与退出

| 操作 | 作用 |
| --- | --- |
| `F8` / 暂停、继续按钮 | 暂停或继续导航，保留本页已累计展示时间 |
| 刷新页面 | 重新加载当前页并暂停；加载完成后按 F8 继续 |
| 个人中心 | 返回个人中心并暂停，按 F8 恢复 |
| `Tab`、`Shift+Tab`、`Enter` | 移动焦点和激活按钮 |
| `Alt+F4` | 退出应用 |

- F8 是应用内快捷键，不是全局快捷键；需要先切回本应用。
- 应用在后台或最小化时，自动导航计时继续。F8 和“暂停/继续”只在本人暂停时停止自动导航。
- 学校仍按自己的规则统计、更新学习记录；展示计时不替代学校记录，也不代表理解课程。
- 休眠、断网或浏览器进程异常不保证继续工作；恢复后请查看底部状态。刷新/重启会重新开始本页展示计时。

## 视频、列表和异常

- 可识别的原生 HTML 视频尝试正常播放，并等待视频结束。视频暂停、缓冲或非原速时不自动切换。
- 如浏览器拒绝自动播放，请通过键盘启动原站播放器。跨域播放器、PDF、图片课程和结构无法识别的页面不承诺自动支持。
- 遇到登录、验证码、多个任务、未知页面或跳转失败时会显示提示；不能保证所有页面都完全无人工操作。
- 网站显示总学时已达标时停止；不会进入考试、代答或调用修改完成状态的接口。
- 学校可能延迟更新学时。成功返回列表后，本地才记录本次已展示课程，避免列表学时尚未同步时反复打开。记录只保留在当前网页会话中，刷新、重新登录或重启后清空。
- 列表稳定后才选课；会跳过网站已达要求的课程，并按顺序翻页。翻页或跳转超过 20 秒未完成会暂停；列表或正文约 30 秒仍无法识别时显示恢复提示。
- 课程识别仍依赖原站列表标题；同一任务有同名课程时，可能需要手动选择。网站布局变化或全部课程已展示但学时未同步时，请核对原站记录。
- 列表翻页及课程结构变化可能需要重新适配。当前适配个人中心下的 `/examTask/…` 任务及阅读详情。

## 系统与隐私

- Windows 10/11 **x64**，.NET Framework 4.6.2 或更高，以及 Microsoft Edge WebView2 Runtime。
- 无需 Python、Node、油猴或浏览器扩展。请保留 EXE 同目录的 DLL；本应用不是单文件 EXE。
- 如果提示缺少 WebView2 Runtime，可从微软官方网站安装：https://developer.microsoft.com/microsoft-edge/webview2/
- 软件仅允许跳转学校域名下的 HTTPS 页面。无需管理员权限；不应绕过证书或系统安全警告。
- 不读取普通浏览器凭据，不保存密码，不导出 Cookie。内置浏览器使用 InPrivate 会话并禁用密码保存/自动填充。
- WebView2 的本机运行数据目录为 `%LOCALAPPDATA%\SDUAccessibleStudy\WebView`。
- 应用 EXE 未进行商业代码签名。

## 验证情况与源码

`App.cs` 是原生窗口，`reader.js` 是仅在学校学习页面运行的导航脚本，`build.py` 负责打包。

开发需要 Windows x64、.NET Framework 自带的 C# 编译器、Python 3.8+；离线检查另外需要 Node.js 18+。无需第三方 Python/Node 包。

```powershell
node check.js
python build.py
```

首次打包需要联网下载微软官方 NuGet 的固定版本 WebView2 SDK（1.0.4191.47），以后使用 `build/webview2.nupkg` 缓存。缓存损坏或版本不匹配时，删除该缓存文件后重新构建。SDK 原许可证随包提供。

输出为 `dist/SDU-Accessible-Study-win-x64.zip`，旁边是 SHA-256 文件。打包仅收录 EXE、三个 DLL、许可证及两份说明，输出目录中的其他文件不会进入压缩包；构建失败保留上一份已完成的 ZIP。

下载后可在 PowerShell 中检查 ZIP 的校验值，与 `.sha256` 中的值比较：

```powershell
Get-FileHash .\SDU-Accessible-Study-win-x64.zip -Algorithm SHA256
```

离线检查覆盖：时间解析、每课时长、后台继续、暂停恢复、通信中断、空列表等待、未学课程选择、课程标题差异、翻页超时重试和返回失败重试。发布前同时检查 Windows EXE 编译、本机 WebView2 可用性、压缩包文件清单与校验值。

本机已读取真实网页的课程目录、计时器和正文结构进行适配。尚未完成独立应用登录后的真实账号端到端验证；不能把离线测试通过视为真实学时提交成功。

## 常见问题

| 现象 | 处理方法 |
| --- | --- |
| 提示缺少运行环境 | 保留全部 DLL，安装上文链接的微软 WebView2 Runtime 后重启 |
| 页面打不开或加载超时 | 检查校园网/VPN，使用“刷新页面”，加载完成后按 F8 |
| 翻页/返回未成功 | 检查原站弹窗和网络，按 F8 重试；仍失败时刷新 |
| 视频未播放 | 用键盘启动原站播放器，再按 F8；缓冲期间等待 |
| 浏览器进程异常 | 使用顶部“重新启动”；需要时重新登录 |
| 所有课程已展示但学校学时未更新 | 等待学校同步并自行核对；刷新后可重新识别 |
